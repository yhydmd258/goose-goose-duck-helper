## 🎯 角色数据结构

每个角色包含以下完整信息：

```typescript
interface Role {
  id: string;                    // 角色ID (英文小写+下划线)
  name: string;                  // 中文名称
  nameEn: string;                // 英文名称
  faction: 'goose' | 'duck' | 'neutral'; // 阵营
  skillDescription: string;      // 技能描述
  usageTips: string;             // 使用建议
  difficulty: 'easy' | 'medium' | 'hard' | 'very_hard'; // 难度
  winCondition: string;          // 胜利条件
  commonStrategies: string[];    // 常用策略 (3-5条)
  precautions: string[];         // 注意事项 (3-5条)
  dialogues: string[];           // 常用说辞/对话
  slang: string[];               // 俗语/黑话
  counterRoles: string[];        // 克制角色ID
  synergyRoles: string[];        // 配合角色ID
  addedInVersion: string;        // 添加版本 (如 "1.0")
  isSeasonal: boolean;           // 是否为季节性角色
  popularity: number;            // 受欢迎程度 0-100
}
```
